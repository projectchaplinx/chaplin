# Director Brain — GPFC (final)

Issued 2026-08-01. The operating contract for Sprint 2 output. Supersedes the
earlier GPFC draft. Extends `DIRECTOR_BRAIN_GPSC.md` (automated verification,
auto-ranking, 6-version matrix, human judgement on outputs).

Preservation contract in `DIRECTOR_BRAIN_GPLC.md` remains in force.

---

## G — GOAL

> Every version renders as a **finished, watchable clip with sound** — character,
> scene, lighting, performance, voice, and mix, complete — and the character
> **sounds like itself in every single one**.

Vocal identity is not a polish step. A character whose voice changes between
clips is not a character, and the follower moat depends on it.

---

## P — PLAN

### P0 — Fix the voice routing first. Nothing renders until this is right.

**Diagnosed cause of "Seedance is making the voice":**

| Model | `audio_reference_input` | `native_audio_output` | Result |
|---|---|---|---|
| `dreamina-seedance-2-0` | **true** | true | Accepts locked voice, lip-syncs to it ✅ |
| `seedance-1-5` | **false** | true | Cannot accept the voice, **invents one anyway** ❌ |
| fallback | false | false | No audio at all |

ElevenLabs is not broken. The key is configured and 25 character voices are
active. The locked voice simply never reaches the render, because the routed
model cannot accept an audio reference — and then that model's native audio
fills the silence with an invented voice.

**`native` never means "Seedance invents speech."** In this codebase `native`
means Seedance *performs the already-rendered locked recording*. `applyOverride`
already throws `"Actor dialogue may never be generated by the video or sound
model."` That guard stays. Do not weaken it.

### Two permitted paths for dialogue

**Path A — lip-sync (preferred).** Route dialogue shots to
`dreamina-seedance-2-0`. Render the locked ElevenLabs line first, pass it as the
audio reference, let Seedance synchronize mouth, breath, and pauses to it.
Constraint: reference length must fit `max_audio_ref_ms` (15 000 ms).

**Path B — post-mix (fallback, works on any model).** Render the shot with **no
generated speech**, then mix the locked ElevenLabs voice over it. Use the
existing `framing_constraint` and off-face patterns — over-shoulder, hands,
profile, listener, rear — so an unsynced mouth is never on camera.

**Selection rule:** if a shot has dialogue and the routed model does not support
`audio_reference_input`, take Path B automatically. Never Path A on a model that
cannot accept the reference.

### Dialogue authoring order — non-negotiable

Words are authored before any render, never discovered afterward.

```
1. Scene is set          — location, beat, story job, fixed in the brief
2. Dialogue text is written and LOCKED   — exact words, in the brief
3. ElevenLabs renders it — the locked character voice speaks those exact words
4. Seedance performs it  — syncs picture to that recording (Path A)
                           or the shot is framed off-face and mixed (Path B)
```

Seedance never authors words. It is handed the exact line and told to perform it.
The existing prompt already does this — it passes `The line is: "..."` and
forbids additional speech, narration, or singing. Keep that.

Any flow where Seedance speaks first and a voice is matched to it afterward is
prohibited. That ordering cannot produce a consistent character voice, because
the words themselves would vary per generation.

### Hard failure rule

If the locked voice is unavailable for any reason, the shot renders **without
dialogue** and is reported as a failed voice stage. It never falls through to
Seedance-invented speech. Fail loud, never fail silently into a wrong voice.

### P1 — Then render the comparison set

```
shot-director → seedance-shot-adapter → elevenlabs-voices → audio-plan → audio-mix
```

No stage skipped. A version failing any stage is recorded as a failed render with
the stage named — not downgraded to a silent clip.

## F — FORMAT

### What every rendered version must contain

| Layer | Requirement |
|---|---|
| **Character** | One locked identity. Same reference chain across every version, shot, and duration. |
| **Scene / world** | Fixed setting, period-correct props and materials. Identical across versions. |
| **Lighting** | A **named motivated source** per shot — window, practical, overhead, firelight. Never "cinematic lighting". |
| **Camera** | Frame size, lens behaviour, position, movement — declared, not implied. |
| **Performance** | The action, the tactic, and what changes in the beat. |
| **Voice** | The character's **locked ElevenLabs voice**, via Path A or Path B. Same line, same delivery, every version. |
| **Sound** | `audio-plan` layers filled: dialogue, ambience, sfx — each with an explicit owner. |
| **Mix** | Final `audio-mix` pass. The clip plays with sound as delivered. |

### Sync requirement

Where dialogue is on camera, mouth, breath and pauses must track the locked
recording. Where sync cannot be guaranteed, the framing constraint moves the
mouth off camera. **Visible bad lip-sync is a hard-gate failure**, scored the same
as identity drift.

### Durations and assembly

| Duration | Structure |
|---|---|
| **5 seconds** | One shot, one story job. |
| **15 seconds** | **Three shots of 5 seconds**, each with a declared continuity handoff. |

Shot length is always 5 seconds; only shot count changes. Every cut in the 15s
arm must be motivated by a change. The handoff records what carries across:
character position, wardrobe, prop state, screen direction, and audio continuity.

### The one thing that varies

Brief, character, voice line, lighting spec, audio plan, and scene are **identical
across all six versions**. The only difference between V0 and V1–V5 is the
injected principle.

Every version displays a **"what changed" line** naming the injected principle and
how it altered the shot instruction. If a version's rendered instruction is
byte-identical to control, record a **null result** — a real finding, not a bug.

### Ceiling

| Item | Value |
|---|---|
| Versions | 6 (V0 control + V1–V5) |
| Durations | 2 (5s, 15s) |
| Keyframe images | 6 |
| Video shots | **24** — 6 × (1 shot at 5s + 3 shots at 15s) |
| Voice renders | **1 locked line**, reused across all versions and durations |
| Mix passes | 12 |
| Cycles per day | 1 |

The voice line is rendered **once** and reused everywhere. Re-rendering it per
version would introduce vocal variation and destroy the comparison.

If the ceiling is too high, cut the 15s arm. Do not cut audio, voice, or lighting.

## C — CHECKS

### Visible without touching the database

- All 6 versions, both durations, **playing with sound**, side by side
- Per version: injected principle, axis, source work, verification verdict, and
  the "what changed" line
- **Which voice path was used** (A lip-sync / B post-mix) and the routed model
- Shared brief, character, voice line, and lighting spec shown once, so what was
  held constant is obvious
- Auto-scores per axis, hard gates called out — **identity drift and bad lip-sync
  flagged loudest**
- For 15s versions: the three shots and their handoffs, individually inspectable
- A **"pick this one"** action recording the promotion

### Exit criteria

- [ ] Voice routing fixed; locked ElevenLabs voice audibly present in every version
- [ ] Zero clips containing a Seedance-invented voice
- [ ] 6 versions rendered complete through mix, both durations
- [ ] Every version shows its "what changed" line; nulls recorded as null
- [ ] `director_evaluations` non-zero
- [ ] Human has picked winners; picks recorded as promotions

### Report after every cycle

Failures first:

1. Any shot where the locked voice failed, with the routed model named
2. Versions that failed a stage, with the stage named
3. Null results — principles that changed nothing in the rendered instruction
4. Identity drift or lip-sync failure between shots in any 15s version
5. Spend against ceiling, and what was skipped because a limit was hit

Control winning is a valid result. Say so plainly.

---

## One risk worth stating

A complete output — voice, lighting, ambience, mix — is rich, and richness can
mask a small craft difference. Mitigation: everything except the injected
principle is identical, and the "what changed" line makes the delta explicit.

If after one cycle the six versions are indistinguishable, the correct conclusion
is that these principles are too weak to matter at this scale — not that the test
failed. Record it and move to the next five candidates.
